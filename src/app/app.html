Credit Card Fraud Detection

A reproducible fraud-classification workflow using the real ULB credit-card dataset, a benchmarked XGBoost model, and a Flask-based prediction API.

Dataset: 284,807 records Target: Class (0 = legitimate, 1 = fraud) Positive rate: 0.17%

Project overview

This project follows the real research paper in the workspace, which compares entropy-computing CVQBoost and XGBoost for financial fraud detection. The model artifact here is trained on the same fraud dataset, evaluated with held-out metrics, and packaged for local inference.

  • Research objective: identify fraudulent transactions while handling severe class imbalance.
  • Methodology: benchmark multiple tabular classifiers and select the best model with F1-score.
  • Deployment: Flask API for local predictions, Angular dashboard for human interaction.

Research limitations and disclaimer

This project uses the verified dataset and paper in the workspace. The public GitHub Pages site displays the project dashboard and genuine evaluation results, but live local predictions require an active Flask API on the machine running the backend. Public deployment of the Flask model is not part of the static site, and prediction output should never be presented as if it were live on GitHub Pages.
